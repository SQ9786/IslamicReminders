# Mihrab

A studio for faceless Islamic reminders. Compose an ayah, a hadith, or an original reminder, preview it as a vertical poster, then download a PNG still or a silent WebM reel for Reels, Shorts, and TikTok.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints. `npm run build` typechecks and writes `dist/`.

Ayah and hadith lines are short English renderings with Arabic beside them. Confirm wording in a mushaf or a trusted collection before posting them as scripture. Lines marked Reminder are original.
